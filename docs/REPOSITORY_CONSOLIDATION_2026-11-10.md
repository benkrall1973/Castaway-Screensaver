# Repository consolidation - 2026-11-10

`Castaway_Screensaver` is the active public repository. The former public and
private repositories had unrelated histories; both are preserved in Git.
Original reference data, installer and forensic material are retained at the
owner's request. Their rights are separate from the GPL source-code license.

Recovery tags preserve the pre-consolidation snapshots. Historical release
metadata and old application binaries remain in Git history and verified offline
backups. The current source tree uses the new branding. Newly built binaries
are distributed through Releases rather than tracked in the source root.
